1行目はヘッダー行として、以下の列名をこの順で含めてください（列の順序は入れ替え可能です）。

姓, 名, セイ, メイ, メールアドレス, 従業員コード, ロール（「一般社員」または「人事」）, 入社日（YYYY-MM-DD）, 部署コード, 役職コード, 上司の従業員コード（任意）

部署コード・役職コードは、部署一覧・役職一覧画面で確認できるコードを指定してください。 上司の従業員コードは、既に登録済みの従業員のコードのみ指定できます（同じCSV内の他の行を上司に指定することはできません）。
